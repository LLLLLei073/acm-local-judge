# ACM 训练工作台重构 Implementation Plan

**Goal:** 提升整个现有项目的实用性与审美，对每项已有功能作出可验证调整，并加入基于真实评测证据的训练与出题辅助。

**Architecture:** 保留 Vue、ASP.NET Core、独立 Worker、SQLite 以及五类引擎；提取共享结果、测试点详情、会话恢复与领域逻辑。选手端围绕继续训练展开，管理端围绕题目准备、验证和发布展开。现有账号、数据、权限、比赛规则与资源口径继续有效。

**Tech Stack:** Vue 3 / TypeScript / Monaco / CSS / ASP.NET Core 10 / C++23。

开始前已将 37 个工作区变更文件与暂存/非暂存差异保存在 `artifacts/refactor-baseline-20261020/`。重构不自动提交或发布。

### Task 1: 建立基线与领域模块
- 记录当前功能与暂存状态；运行现有构建。
- 提取训练统计、解决状态、资源诊断、出题检查和批量数据配对。
- 用边界样例验证曾经 AC、最新失败、账号隔离、超限与缺失配对。

### Task 2: 统一运行证据与连接管理
- 新建共享结果和测试点详情组件，替换两端重复模板。
- 建立有生命周期管理的 SSE + 轮询恢复机制。
- 完成五类判题、取消、历史打开的回归验证。

### Task 3: 重建选手体验
- 应用训练台视觉系统；加入训练概览、排序、继续训练与账号草稿。
- 改进比赛、榜单、登录和个人设置；保留既有业务规则。
- 验证窄屏、键盘、刷新与浏览器实际路径。

### Task 4: 重建出题体验
- 改进数据、源码、通信、AI预览、准备检查、批量筛选与管理工具。
- 拆分共享逻辑，避免继续扩大两端单文件重复。
- 验证建题、上传、验证、发布、比赛分组、ZIP往返。

### Task 5: 全量验证与交付
- 运行 TypeScript 与生产构建、四套原生/API测试、领域/连接测试。
- 用独立测试数据目录跑浏览器完整流程，不改动业务数据库。
- 更新本表的证据与验证报告；没有充分证据的项目继续保留为未完成。
