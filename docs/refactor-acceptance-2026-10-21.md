## 验收范围与保留边界

- 保留 Vue、ASP.NET Core、独立 Worker、SQLite、五种引擎及原有比赛/权限规则。创新点建立在真实数据上：训练概览、邻近难度推荐、共享运行证据、成员时序图、出题准备检查和可审核 AI 提议。
- 测试运行在 Windows，服务和浏览器使用 `artifacts/refactor-browser-data/`。没有写入业务 `data/`。390px 验证使用同源固定宽度 iframe，核对了实际文档尺寸及截图；不是手机真机验收。
- AI 使用本地 OpenAI 兼容 fixture，没有提交真实密钥或调用第三方模型；CF 自动化使用本地 API 桩，没有修改真实 CF 账号。
- Linux 真机、公网恶意代码隔离、外部 AI 提供商差异和大规模负载不在本轮新增验证承诺中；既有部署说明与可信代码边界继续有效。前端仍有 Monaco/AI 大包提示，接口测试保留已有 nullable 警告。
- 用户此前要求推送的版本已上传为 `2cc4578`；之后的本轮修复仍在本地工作区，没有自动再次提交或推送。

本轮完成审计依据是上述逐功能源码与执行证据，不以通过数量代替范围核对。
